# Bulk RNA-seq Analysis and Reproducible Pipeline

Take raw RNA sequencing data, turn it into biological findings, then automate the whole process so anyone can rerun it.

## Status
Work in progress, started October 2026.

## Plan
1. Analyse a count matrix with DESeq2 in R, to understand the biology first
2. Build the upstream pipeline (quality control, alignment or quantification) in Nextflow
3. Add containers, tests and automatic checks
4. Write a report with the results
